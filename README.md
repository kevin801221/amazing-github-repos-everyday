## 🎯 我們怎麼找到這些黑馬？

```
篩選條件  →  近 30 天內建立  +  topic:ai / topic:llm  +  星數快速累積
排序邏輯  →  成長性 = 總星數 ÷ 建立至今天數（不是看總星數！）
刻意排除  →  老牌大專案、已經人盡皆知的 repo
```

**為什麼這個方法有效？**

- GitHub Trending 看的是「短期增量」，我們看的是「從零到一的加速度」
- 30 天窗口剛好能抓到新專案的第一波爆發期
- 成長性排序讓 3 天 594 星的 Talos 也能跟 21 天 7 萬星的 ponytail 同台競爭
